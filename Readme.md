# Customer Segmentation Project

A complete end-to-end analysis of customer behavior using SQL, Python, and Tableau. This project explores how different customer segments vary in spending, purchase frequency, loyalty, and overall distribution, helping businesses understand which groups drive value and which require attention.

## Project Overview

This project performs a full customer segmentation workflow:

- Clean and prepare customer data
- Analyze spending, frequency, and loyalty metrics
- Segment customers into meaningful groups
- Visualize insights using a professional Tableau dashboard
- Package results for GitHub, LinkedIn, and portfolio presentation

## Key Insights

- Segment 1 shows the highest average spend, indicating strong revenue potential.
- Segment 3 has high loyalty scores, making it ideal for retention strategies.
- Segment 0 has low purchase frequency, suggesting an opportunity for engagement campaigns.
- Segment distribution reveals how customers are spread across groups, helping with resource allocation.
