# 📊 Customer Segmentation Project

A complete end-to-end analysis of customer behavior using **SQL**, **Python**, and **Tableau**. This project identifies how customer groups differ in spending, purchase frequency, loyalty, and overall distribution — helping businesses understand which segments drive value and which require strategic attention.

---

## 🔍 Project Overview

This project performs a full customer segmentation workflow:

- Clean and prepare customer data  
- Analyze spending, frequency, and loyalty metrics  
- Segment customers into meaningful groups  
- Visualize insights using a professional Tableau dashboard  
- Package results for GitHub, LinkedIn, and portfolio presentation

## 📈 Tableau Dashboard

The final dashboard visualizes four key metrics across customer segments:

- Segment distribution  
- Average spend  
- Purchase frequency  
- Loyalty score  

### Dashboard Preview

![Customer Segmentation Dashboard](assets/images/customer_segmentation_dashboard.png)

---

## 🔑 Key Insights

- **Segment 1** shows the highest average spend — strong revenue potential.  
- **Segment 3** demonstrates high loyalty — ideal for retention strategies.  
- **Segment 0** has low purchase frequency — an opportunity for engagement campaigns.  
- Segment distribution reveals how customers are spread across groups, guiding resource allocation.
